🔑 API AI (OpenRouter)

Lấy key tại openrouter.ai/keys · Key lưu trên từng máy (không đưa lên Firebase).

⚠️ Mỗi thiết bị cần dán API key một lần. Chat thì đồng bộ; key thì giữ local cho an toàn.
